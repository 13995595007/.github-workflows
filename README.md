# .github-workflows

## 小朋友奖惩机制小游戏（可预览演示）

已提供可直接在浏览器打开的互动页面：`kid-reward-game.html`。

### 亮点
- 情境选择式玩法（好行为 / 坏行为）。
- 奖惩积分与星星成长系统。
- 连胜机制（连续好选择解锁徽章）。
- 奖励宝箱建议（达到分数后解锁）。
- 可切换难度（简单 / 普通 / 挑战）。
- 自动保存进度（localStorage）。

### 本地加载预览演示
在仓库目录执行：

```bash
python3 -m http.server 8000
```

然后访问：
- `http://localhost:8000/kid-reward-game.html`

### 基础规则
- 简单：好行为 +2，坏行为 -2
- 普通：好行为 +3，坏行为 -2
- 挑战：好行为 +4，坏行为 -3
- 最低分不低于 0 分
- 每 5 分获得 1 颗星星
