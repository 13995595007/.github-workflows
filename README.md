# .github-workflows

## 小朋友奖惩机制小游戏（可预览演示）

已提供可直接在浏览器打开的互动页面：`kid-reward-game.html`。

### 亮点
- 情境选择式玩法（好行为 / 坏行为）。
- 奖惩积分与星星成长系统。
- 连胜机制（连续好选择解锁徽章）。
- 奖励宝箱建议（达到分数后解锁）。
- 可切换难度（简单 / 普通 / 挑战）。
- 自动保存进度（localStorage）。

### 本地加载预览演示
在仓库目录执行：

```bash
python3 -m http.server 8000
```

然后访问：
- `http://localhost:8000/kid-reward-game.html`

### 基础规则
- 简单：好行为 +2，坏行为 -2
- 普通：好行为 +3，坏行为 -2
- 挑战：好行为 +4，坏行为 -3
- 最低分不低于 0 分
- 每 5 分获得 1 颗星星

## 怎么测试

### 1) 自动化冒烟测试（推荐）
在仓库目录执行：

```bash
python3 scripts/test_kid_reward_game.py
```

这会校验：
- 关键 UI 元素是否存在（积分、星星、连胜、按钮、难度选择）。
- 核心规则是否存在（最低分不低于 0、星星计算规则）。
- 难度配置是否正确（easy/normal/hard）。
- `localStorage` 持久化逻辑是否存在。

### 2) 手动功能测试
1. 启动本地服务器：
   ```bash
   python3 -m http.server 8000
   ```
2. 打开 `http://localhost:8000/kid-reward-game.html`。
3. 逐项检查：
   - 点击“选择好行为”是否加分。
   - 点击“选择坏行为”是否扣分，且不会小于 0。
   - 分数变化后星星是否按 `floor(score / 5)` 更新。
   - 切换难度后，加减分是否按规则变化。
   - 刷新页面后，积分/日志/难度是否保留。
   - 点击“重新开始”是否重置进度。
